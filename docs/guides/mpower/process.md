Completați [Formularul unic de conectare](https://forms.office.com/pages/responsepage.aspx?id=Z4f8jWsRaEKDxfvIWTRtOHwLku9yOJZAs22J7gTUxBNUMFhISEJPMUNGOTIwV09OTkFTUUtLSk9LTS4u&route=shorturl); 
Semnați contractul și/sau anexa privind utilizarea serviciilor MPower; 

Pentru fiecare autorizare, instituția se asigură că este completat [Formularul de creare a tipului de autorizare](https://docs.google.com/document/d/1crNGXeM5SnvwzILyIFEUnpN5Svl-xFBN/edit). 

În cazul integrării prin API: 

  - Instituția implementează conexiunea API în conformitate cu documentația tehnică și efectuează testele funcționale; 
  - AGE configurează accesul instituției la mediul de testare; 

În cazul creării autorizărilor în MPower: 

  - AGE asigură configurarea autorizărilor în MPower; 
  - Instituția verifică configurările și validează corectitudinea acestora. 

După validarea finală, AGE activează autorizările în mediul de producție; 
Instituția primește notificarea privind finalizarea integrării.
