# API reference

The eProgramari API is exposed by the portal under the `/e-appointment-api` path (for example, `https://programari.gov.md/e-appointment-api/`) and lets institutions' information systems integrate with the online appointments service.

!!! note "Coming soon"
    The full list of methods (endpoints, parameters, request and response structures) will be published from the service's OpenAPI (Swagger) specification.

## Error Handling

| Code | Description |
|---|---|
| 200 | Success |
| 400 | Bad request |
| 401 | Unauthorized |
| 403 | Forbidden |
| 404 | Not found |
| 500 | Server error |
