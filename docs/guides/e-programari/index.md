# eProgramari

eProgramari ([programari.gov.md](https://programari.gov.md)) este portalul guvernamental pentru programări online la serviciile publice. Cetățenii aleg instituția, serviciul, data și ora potrivite și își fac programarea fără a crea un cont, iar instituțiile își configurează serviciile, intervalele orare și își gestionează programările într-un singur loc.

Portalul expune un **API** prin care sistemele informaționale externe ale instituțiilor se pot integra cu serviciul.

## Pe scurt

**Ce este.** Serviciul prin care persoanele fizice fac programări online la serviciile publice oferite de instituțiile conectate, iar instituțiile publică serviciile programabile, definesc intervalele orare și administrează solicitările. Lista instituțiilor și a serviciilor este în continuă extindere.

**Pentru cetățeni.**

- Nu este necesar un cont — este suficient să completați formularul online.
- Datele solicitate sunt: numele și prenumele, IDNP sau actul de identitate, adresa de e-mail, numărul de telefon și, în unele cazuri, adresa de domiciliu.
- După finalizare, solicitantul primește un mesaj de confirmare pe e-mail, cu un link pentru modificarea sau anularea programării.
- Programarea se poate face și pentru o altă persoană, cu datele corecte și acordul acesteia (dacă este majoră).
- Programarea este disponibilă și din aplicația mobilă EVO.

**Autentificare cu semnătură electronică.** Pentru acțiunile care necesită identificare, portalul acceptă semnătura USB (aplicația MoldSign), cartea de identitate, semnătura mobilă (Orange, Moldcell) și EVOSign.

**Pentru instituții.** Conectarea se face în trei pași:

1. **Transmiteți solicitarea** — completarea unui formular simplu pentru inițierea procesului de conectare.
2. **Configurați serviciile disponibile** — alegeți ce tipuri de servicii pot fi programate online și definiți intervalele orare.
3. **Gestionați programările** — administrați solicitările și controlați programul.

Solicitarea de conectare se depune prin [formularul dedicat](https://forms.office.com/e/p8n69by5NZ).

**Cui se adresează acest ghid.**

Principal: echipele de dezvoltare și integrare ale instituțiilor care doresc să-și conecteze sistemele informaționale cu eProgramari.
Secundar: managerii de proiect și responsabilii de servicii care pregătesc conectarea instituției.
