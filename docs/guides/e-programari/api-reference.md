# Referință API

API-ul eProgramari este expus de portal sub calea `/e-appointment-api` (de exemplu, `https://programari.gov.md/e-appointment-api/`) și permite sistemelor informaționale ale instituțiilor să se integreze cu serviciul de programări online.

!!! note "În curând"
    Lista completă a metodelor (endpoint-uri, parametri, structuri de request și response) va fi publicată din specificația OpenAPI (Swagger) a serviciului.

## Gestionarea erorilor

| Cod | Descriere |
|---|---|
| 200 | Succes |
| 400 | Cerere invalidă |
| 401 | Neautorizat |
| 403 | Interzis |
| 404 | Nu a fost găsit |
| 500 | Eroare de server |
