| Termen | Definiție |
|------|------------|
| API | Interfață de programare a aplicațiilor (Application Programming Interface) |
| Blob | Reprezintă conținutul unui document |
| Body | Conținutul mesajului |
| CA | Autoritate de certificare (Certificate Authority) |
| CBOR | Concise Binary Object Representation |
| CDDL | Concise Data Definition Language |

| EUDI | Identitate digitală europeană (European Digital Identity) |
| Event | O acțiune sau un fapt petrecut într-un Sistem Informațional, la un anumit moment de timp |
| GET | O metodă standard de solicitare HTTP |
| HTTP | Hypertext Transfer Protocol |
| HTTPS | Hypertext Transfer Protocol Secure |

| OpenID4VP | OpenID for Verifiable Presentation |

| TLS | Transport Layer Security |
| TSL | Listă de stare a token-urilor (Token Status List) |
| URI | Identificator uniform de resursă (Uniform Resource Identifier) |

| URN | Nume uniform de resursă (Uniform Resource Name) |

| WS | WebSocket, un protocol de comunicare bidirecțională simultană, care funcționează peste HTTP |
| WSS | WebSocket Secure, extensie a WS care utilizează criptare pentru comunicare, bazată pe TLS |
